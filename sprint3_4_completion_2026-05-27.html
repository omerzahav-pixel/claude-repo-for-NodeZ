2. עשרת ה-issues — סיכום אישי

Issue 1 — הסרת ה-breadcrumb בצד ימין למעלה CLEANUP

ה-#bc הציג את שרשרת ה-Workspace → Parent → Current. ה-drawer כבר מציג את זה באופן קבוע, אז ה-breadcrumb היה מיותר. הוסתר תחת body.nav-v2-on; חוזר כשהפלאג כבוי (rollback).

Issue 2 — היררכיה תלת-רמתית ב-drawer: canvas → zone → node FEATURE

ה-canvas הפעיל מתרחב עכשיו לשורות-zone (chip צבע + שם + count + caret), וכל zone מתרחב לרשימת ה-nodes שלו. תקיעה ב-zone מקפיצה את הקנבס למרכז ה-zone (window.focusZone חדש ב-app.js), תקיעה ב-node ממקדת אותו. ה-bucket "Unzoned" רנדר רק כשיש zones וגם nodes לא-מסווגים, אחרת זה רעש.

מצב ההתרחבות נשמר ב-localStorage['edgespace-drawer-zone-open'] לכל canvas בנפרד.

Issue 3 — הסרת הסרגל הישן בצד שמאל-תחתון CLEANUP

ה-#sb ("Nodes / Edges / Zones") היה כפול ל-drawer החדש אחרי Issue 2. הוסתר תחת body.nav-v2-on — וגם הכפתור #sbBtn שלידו, כי הוא היה לוחץ על כלום אחרי ההסתרה.

Issue 4 — קידום 4 chips ל-spine + מעבר של ה-search pill FEATURE

ה-chips החדשים: Search (החליף את ה-pill הצף שהיה במרכז למעלה), Undo (מצב disabled מסונכרן עם #undoBtn.disabled דרך wrap של bB()), Import (תווית <label for="imp"> כדי לשמר את user-gesture ל-iOS), Lang. הוסרו משלושת המקומות שהיו ב-Tools panel.

דרשו להעביר את #imp ו-#impC החוצה מ-#tb כדי שייבוא יעבוד גם כש---toolbar-migrated מסתיר את ה-toolbar הישן.

Issue 5 — Kanban עם 5 עמודות במקביל ב-iPad FEATURE

ה-grid עבר ל-repeat(5, minmax(180px, 1fr)). 180 px זה הרצפה — מתחת לזה (iPad פורטרייט עם drawer פתוח) יש overflow-x: auto. כל עמודה גוללת אנכית בנפרד כדי שעמודה גודשת לא תדחוף את האחרות. ב-RTL ה-container מקבל direction: rtl וסדר העמודות מתהפך (Done משמאל, Idea מימין).

הסרתי את ה-@media (max-width: 920px) שהיה מקפל ל-2 עמודות; iPad Pro פורטרייט (1024) נשאר עם 5.

Issue 6 — Weak-spot פר-workspace FEATURE

API חדש: isWeakspotEnabled / setWeakspotEnabled מאוחסן ב-localStorage['edgespace-weakspot:<ws>']. ברירת מחדל OFF לכל workspace, עם מיגרציה חד-פעמית שמדליקה רק את workspace בשם "uni" אם קיים. ה-view-tab של Weak-spot מוסתר כש-disabled; הסתרה אוטומטית מעבירה לקנבס אם המשתמש היה ב-weakspot.

המודאל ל-Workspace settings ב-Tools panel (שורה חדשה) חושף את הטוגל. ה-view-tabs מבצע re-render גם אחרי כל switch של workspace.

Issue 7 — Clear Canvas מנקה גם zones BUG

clr() עכשיו מאפס nodes + edges + zones בטרנזקציה אחת. Undo בודד מחזיר את שלושתם. ה-bug שדיווחת — מלבנים נשארים אחרי "Clear canvas" — נסגר.

Issue 8 — Clear Canvas עם cascade-delete FEATURE

פונקציה חדשה clearCanvasWithCascade (נגישה דרך Tools panel → "Clear canvas"). כשיש portal nodes (כלומר node-ים עם childCanvas מוגדר) — מודאל עם ספירת הנכדים והאפשרות לאישור cascade. gatherDescendantCanvasIds הולך depth-first על העץ. Cascade דולק = מחיקה רקורסיבית בטרנזקציה אחת. Cascade כבוי = ה-portal nodes נמחקים אבל הקנבסים שלהם נשארים נגישים מהשורש (parentCanvas + parentNodeId מתאפסים).

בלי portals → אין מודאל, רק uiConfirm רגיל.

Issue 9 — Drag-reorder נדחה ל-FR-3 DEFER

כפי שאישרת בשאלה הפותחת. הסיבה: הוספת gesture שלישי של long-press על iPad (יש כבר add-node-here ו-drawer-row context menu) הייתה מסתבכת. נכנס ל-FEATURE-REQUESTS.md כ-FR-3.

Issue 10 — תיעוד ה-spine DOCS

הדיאגרמה למעלה. כל chip ותפקידו, סדר אנכי מדויק כמו שזה רנדר על המסך.

3. בונוס — iPad URL מתמיד

בלי Develop / Console

ה-flags.js כבר תמך ב-?flags=a,b,c ב-URL, אבל זה היה תקף רק לסשן הנוכחי. עכשיו הוא גם שומר את הפלאגים מה-URL ל-localStorage בביקור הראשון.

זה אומר שאתה יכול לפתוח על ה-iPad פעם אחת את ה-URL הבא, להוסיף לסימניות, ומכאן והלאה כל פתיחה רגילה של nodez-2iz.pages.dev תזכור את הפלאגים:

https://nodez-2iz.pages.dev/?flags=nav-v2,palette,views-v2,silhouettes,edges-v2,zones-v2,rtl-v2,gestures-v2,toolbar-migrated,raf-throttle,lifecycle-v2,webfont

כל פלאג שמופיע פעם אחת ב-URL נכתב ל-localStorage. אם רוצים לכבות פלאג בעתיד — אפשר ?flag=-nav-v2 (מינוס מסמן OFF) או פשוט מ-Console רגיל.
